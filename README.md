# HUMIS-Homepage

A static HTML and CSS project modeled on the University of Utah’s History Department website.
Use the homepage sidebar to explore faculty profiles, student information, courses and syllabi, 
and department news.

## What I learned

HUMIS project is a very advanced website for a beginner class. 
Not that I am saying it is hard but was a good challenge into the deep end. 
I learned a lot about building a appealing website using the html and css elements.
I took a class on html and css in high school but this class actually taught me 
how to build a website with these elements instead of a video and automated guidebook.
Teaching me how to use the &. and &: functions to assign parent to class vs a reserve key word.
I also learned to nest many many many attributes into a container. 

## How I benefited from this project

The knowledge from this class will definitely be helpful in the future for securing a job or internship. 
The use of GITHUB is a very important tool that I must not forget. I will be using GITHUB for things 
in the future as it is a powerful resource for storing past versions. Learning to build a website 
gives me insight into the inner-workings of a web developer. Allowing me to better understand what the relation of UX deisgn and web dev. 
Just because I have a UX degree does not guarantee I will get a position as a UX designer.
I could land a role as a web developer and spend most o my time in the code.



## What I would change

A few things I would do differently with the process would be to build a reusable component
for my nav bar and other aspects on my page. I had to give certain attributes its own style in the 
html attribute when I should have nested a category to store that whole style set. 
I used many images in this website across 13 pages. I had to download each one of those images individually.
I do not like to download a lot of files in general into Finder because, 
I will forget or be too lazy to go through it all and delete.
